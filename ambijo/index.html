Cara Menggunakan Ambiljon

Aplikasi ini merangkap data produk dari struktur HTML Amazon tanpa batas halaman (Cumulative Mode).

  1. Buka Amazon, cari produk target Anda.
  2. Inspect element, cari kontainer pencarian utama (biasanya div.s-main-slot).
  3. Copy innerHTML dari elemen tersebut.
  4. Paste di Terminal Input aplikasi ini, lalu klik Proses.
  5. Buka halaman 2 di Amazon, ulangi proses paste dan klik Proses. Data baru otomatis ditambahkan.
