Syarat & Ketentuan Penggunaan

Aplikasi SubSync Studio berjalan 100% di sisi klien (browser lokal Anda). Seluruh pembacaan biner video MP4 (atom ftyp/moov/stts), pratinjau video, dan penyuntingan file subtitle .SRT diproses langsung di memori perangkat Anda tanpa pernah diunggah ke server eksternal mana pun.

Tidak ada paksaan dalam menggunakan aplikasi ini. Aplikasi ini disediakan 'as-is' (sebagaimana adanya) dan akurasi hasil tidak dijamin. Pembuatan aplikasi ini dibantu oleh AI tools. Aplikasi ini menggunakan Google Analytics dan Histats untuk mengumpulkan data statistik kunjungan dan penggunaan anonim guna pengembangan fitur, tanpa merekam identitas pribadi. Pembuat dibebaskan dari segala bentuk konsekuensi, kerugian, atau tuntutan apapun yang timbul dari penggunaan aplikasi ini. Penggunaan aplikasi berarti Anda menyetujui ketentuan ini sepenuhnya.
