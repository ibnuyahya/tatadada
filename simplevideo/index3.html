Tips Tata Letak Visual: Untuk tipe konten yang sangat visual (seperti Drag and Drop, Course Presentation, atau Hotspots), AI hanya menyuntikkan teks materi Anda ke dalam cangkang. Letak atau ukuran kotak mungkin menjadi berantakan. Anda cukup membukanya di editor H5P LMS Anda dan menggeser/mengecilkan kotak-kotaknya secara manual.

Trik Khusus Permainan (Matrix): AI tidak dapat menghitung matriks koordinat (X,Y) teka-teki silang dengan presisi. Jika file H5P error (blank) saat diunggah ke Moodle, buka file tersebut di Lumi Editor, klik Edit, lalu langsung klik Save. Lumi akan otomatis mengkalkulasi ulang matriksnya secara sempurna!
Solusi Error Moodle "get_content() on false": Jika file H5P memunculkan error PHP ini saat diunggah ke Moodle, itu BUKAN karena JSON Anda rusak. Hal ini terjadi karena Anda menggunakan file ber-versi library terbaru yang belum terinstall di Moodle. Solusi 1: Hubungi Admin untuk Update Pustaka H5P. Solusi 2: Unggah file tersebut ke dalam Content Bank Moodle terlebih dahulu agar Moodle bisa mempelajari pustaka barunya.
