⚠️ SharedArrayBuffer / COOP & COEP Terblokir

FFmpeg WASM memerlukan lingkungan terisolasi yang aman agar dapat berjalan di browser Anda. Server hosting Anda saat ini belum mengirimkan header keamanan yang diperlukan.

Pilih metode konfigurasi server Anda:

Karena domain Anda menggunakan Cloudflare, Anda dapat mengaktifkannya langsung tanpa mengubah kode server:

  1. Buka Dashboard Cloudflare Anda.
  2. Masuk ke menu Rules > Transform Rules > Modify Response Header.
  3. Klik Create rule, beri nama bebas (misal: "FFmpeg Headers").
  4. Atur kecocokan jalur: URI Path starts with /simplevideo/
  5. Atur Set static header dengan ketentuan:
    • Cross-Origin-Opener-Policy = same-origin
    • Cross-Origin-Embedder-Policy = require-corp

Buat atau tambahkan kode berikut ke dalam file .htaccess di dalam folder /simplevideo/ Anda:

<IfModule mod_headers.c>
    Header set Cross-Origin-Opener-Policy "same-origin"
    Header set Cross-Origin-Embedder-Policy "require-corp"
</IfModule>

Tambahkan baris berikut di dalam blok konfigurasi server atau location Nginx Anda:

add_header Cross-Origin-Opener-Policy "same-origin";
add_header Cross-Origin-Embedder-Policy "require-corp";
